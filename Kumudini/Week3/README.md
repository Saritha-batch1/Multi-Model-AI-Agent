## Milestone 2: Pattern Recognition & Contextual Analysis

This milestone builds advanced analytical logic on top of CBC data processing.

### Features
- Supports **CSV, JSON, PDF, and Image (OCR)** blood reports  
- Classifies CBC parameters using standard reference ranges  
- **Model 2:** Detects medical patterns (e.g., anemia, infection, bleeding risk) using parameter combinations  
- **Model 3:** Applies contextual analysis using **age and gender**  
- Generates structured **JSON health reports** with findings and recommendations  

### Output
- Parameter-wise status (Low / Normal / High)  
- Identified clinical patterns and risk flags  
- Context-aware recommendations for further action  

This milestone enables explainable, rule-based health risk assessment without external APIs.
